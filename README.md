# 🌐 Fuyad — Personal Portfolio Website

Welcome to my personal portfolio website! 🚀

This is a modern, responsive, and interactive **Front-End Developer Portfolio** built to showcase my skills, services, projects, experience, and contact information.

The website focuses on a clean UI, smooth animations, responsive layouts, and an engaging user experience across desktop, tablet, and mobile devices.

👉 **Live Website:** https://fuyad254.github.io/My-Personal-Portfolio-Website/

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Portfolio
```

### 3. Run the project

Simply open the `index.html` file in your browser.

For the best development experience, you can also use **VS Code with the Live Server extension**.
